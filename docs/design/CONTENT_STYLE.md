# Content & Voice

The user may be frightened and has seconds. Copy is a safety surface.

## Rules

1. **Calm, never alarming.** "Help is on the way" ✓ · "EMERGENCY ACTIVATED" ✗
2. **Concrete, never vague.** "Message sent to Mum and 2 others" ✓ ·
   "Notifying your contacts" ✗ — vagueness is what made the old SOS screen misleading
3. **Honest about failure.** "Couldn't reach Dad — no signal. Retrying." Hiding
   failure is worse than admitting it
4. **Short.** Nobody reads a paragraph while frightened
5. **Second person, present tense.** "You're sharing your location with 2 people."
6. **No jargon.** No "geofence", "payload", "neural", "AI-powered"
7. **Numbers, not adjectives.** "±18 m, 2 minutes ago" ✓ · "approximate" ✗

## Prohibited claims

"Police alerted" (unless `canClaimDispatch`) · "AI detects attacks" · "evidence can
never be deleted" · "works offline" unqualified · "legally admissible" · any unmeasured
accuracy number · any success not backed by a verified record.

## State vocabulary — use exactly these

| Reality               | Say                           | Never say               |
| --------------------- | ----------------------------- | ----------------------- |
| Queued                | "Sending…"                    | "Sent"                  |
| Provider accepted     | "Sent"                        | "Delivered", "Notified" |
| Receipt confirmed     | "Delivered"                   | "They know"             |
| Human responded       | "Maya is responding"          | —                       |
| Channel can't confirm | "Sent · delivery unconfirmed" | "Delivered"             |
| Nothing got out       | "Couldn't reach anyone"       | "Alert sent"            |

"Notified" is banned as a UI word. It conflates three different truths.
